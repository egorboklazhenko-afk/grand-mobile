# Grand Copilot — конкурсная поставка 1.1

## Назначение и архитектура
Ассистент поддержки Grand Mobile: входное обращение → нормализация языка → триаж → поиск правил → проверка ссылок → черновик → администратор.

В поставку входят автономный HTTP-сервис POST /triage, пакетное предсказание JSONL, Windows-программа и инструкции воспроизведения. Внешний Groq используется для семантической классификации и RAG-черновика. При недоступности модели или отклонении ответа сохраняется локальный режим. Интерфейс явно показывает замену AI-ответа локальным шаблоном.

## Внесённые доработки
- Разделены потеря имущества и взлом/потеря доступа: обязательная эскалация сохранена, критический приоритет применяется к компрометации доступа.
- Расширены признаки обращений на русском, казахском, узбекском, английском, испанском и португальском.
- Ник и номер сервера извлекаются из текста; учитываются приложенные материалы и ссылки. Наличие ссылки или вложения не означает проверки содержимого.
- Дубликаты одного заявителя сравниваются после нормализации регистра, пробелов и пунктуации; учитываются часовой интервал и цель жалобы.
- Для общего DM не выдумывается номер правила: цитируется пункт 1.1.1 раздела «Правила жалоб» о рассмотрении жалоб на основании объективных доказательств. Для зелёной зоны и территории дома выбираются соответствующие существующие пункты.
- В запросы модели не передаются ответы администратора, исход, наказание и другие поля разметки. Лишние идентификаторы также исключены из внешнего контекста.
- Добавлен предварительный консервативный допуск стоимости Groq по размеру UTF-8, резерву протокола, максимальному выводу и настроенным ставкам. Слишком большой запрос не отправляется. Это оценка допуска, не измерение счёта провайдера.

### Синтетическая регрессия
32 авторских сценария на шести языках: совпадение категории 32/32; macro-F1 приоритета 1.0; определение языка 32/32. Проверены платежи, взлом, пропажа имущества, помощь, жалобы, апелляции и вопросы. Матрица сценариев находится в tests/test_submission.py.

Эта выборка создана для регрессионной проверки и не является независимым или скрытым конкурсным тестом. Результат нельзя переносить на реальные обращения. В выданной валидации нет эталонных категории и приоритета, поэтому accuracy/macro-F1 на ней не заявляются как измеренные. Официальная оценка качества черновиков остаётся за жюри.

## Groq и стоимость
Участник команды сообщил об успешной пользовательской проверке программы с Groq. По его указанию повторная проверка внешней модели в этой итерации не выполнялась. Сведения об этом не выдаются за нагрузочное измерение или независимую экспертизу языкового качества.

Основная конфигурация: GroqCloud, openai/gpt-oss-120b, strict JSON Schema, low reasoning. Ставки в конфигурации: $0.15 за миллион входных и $0.60 за миллион выходных токенов. Пример расчёта, не фактический замер: 2000 входных + 1200 выходных = $0.00102. После вызова оценка вычисляется по usage. При отсутствии usage или неизвестной оплате ошибки стоимость не подменяется нулём.

Показатель p95 HTTP выше относится к локальному режиму. Реальные стоимость и задержка внешней модели в этой итерации не измерялись. Перед эксплуатацией тарифы проверяются по документации провайдера.

## Границы полномочий
Утверждения заявителя и обвиняемого сохраняются отдельно и не считаются доказанными. Содержимое скриншотов недоступно. Сервис не обещает наказание, возврат средств или разбан. Платежи, аккаунты и апелляции требуют администратора. Принятие черновика сохраняет обратную связь, а не отправляет сообщение игроку.

Confidence — некалиброванная эвристика. Нулевая ошибка существования ID не доказывает смысловую релевантность всех цитат. Шаблоны на kk/uz проверены функциональными сценариями, но независимая оценка носителями не заявляется. Без проверенной базы игровых инструкций конкретные шаги механик не выдумываются.

## Воспроизведение
1. В корне репозитория: python setup_data.py --archive «архив организаторов.tgz» --with-tickets.
2. python verify_submission.py — приёмочная проверка без внешних API.
3. python -m copilot.server — HTTP-сервис, по умолчанию 127.0.0.1:8765.
4. make predict IN=tickets.jsonl OUT=pred.jsonl — контракт пакетного запуска.
5. Без Make: python -m copilot.cli --input tickets.jsonl --output pred.jsonl.
6. Windows: готовый Grand Copilot.exe из отдельного ZIP; импорт правил и ключ Groq вводятся в Настройках.

Требуется Python 3.12+ для исходников; сторонние Python-библиотеки API/CLI не нужны. Для готового EXE Python не нужен, используется системный WebView2. Dockerfile приложен, но Docker в этой среде отсутствует и сборка контейнера не проверялась. Схема API: OPENAPI.json. Машинные отчёты: reports/.

## Конфиденциальность и состав поставки
Данные кейса, rules.json, taxonomy.json, личные сохранения и ключи исключены из архива. Правила импортируются из архива организатора. Все демонстрационные тексты вымышлены. SHA256SUMS.json позволяет проверить состав файлов. Код и данные имеют разные условия использования; см. NOTICE.md и licenses/.
