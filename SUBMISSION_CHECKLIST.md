# Проверка состава сдачи

| Требование | Реализация / проверка |
|---|---|
| POST /triage | copilot/server.py, HTTP-проверка verify_submission.py |
| make predict | Makefile; тот же CLI проверен на 10 примерах |
| Категория, приоритет, язык, извлечённые поля | Engine; 32 синтетических регрессионных сценария |
| RAG и цитаты | RuleIndex; 1000 обращений без несуществующих ID, только нумерованные пункты |
| Эскалация | Обязательные категории и отдельные safety-сценарии |
| Работа без внешней модели | Проверена; fallback виден в интерфейсе |
| Дедупликация | Нормализованный текст, заявитель, цель, сервер, один час |
| Интерфейс и обратная связь | Пересобранный EXE, тест записи и восстановления очереди |
| Отчёт, стоимость, latency | REPORT.html и reports/*.json; области измерений явно разделены |
| Конфиденциальность поставки | Нет data, runtime, user-data, ключей и исходных выборок |

Ни один технический тест не является гарантией баллов скрытого теста. Независимая оценка качества черновиков и kk/uz в эти результаты не включена.
